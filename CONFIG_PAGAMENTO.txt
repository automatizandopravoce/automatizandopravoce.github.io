==============================================================================
GUIA DE VERIFICAÇÃO REAL DE PAGAMENTO PIX (COMO FUNCIONA NA PRÁTICA)
==============================================================================

Para que o site LIBERE O ARQUIVO SOMENTE QUANDO O CLIENTE REALMENTE PAGAR, 
o site precisa conversar com o Banco Central ou com uma instituição financeira.

Uma chave Pix pessoal comum (como seu e-mail ou CPF no Nubank/Inter/Itaú) NÃO avisa
automaticamente um site que o dinheiro caiu na conta. Nenhum site no mundo consegue
adivinhar isso sem uma conexão bancária oficial.

Existem DUAS FORMAS de fazer isso funcionar no seu site:

------------------------------------------------------------------------------
OPÇÃO 1 (A MAIS RECOMENDADA E FÁCIL): USAR UMA PLATAFORMA (KIWIFY OU KIRVANO)
------------------------------------------------------------------------------
É como 99% dos vendedores de infoproduto no Brasil fazem hoje:
1. Você cria uma conta gratuita na Kiwify (kiwify.com.br) ou Kirvano (kirvano.com).
   - Não paga nada de mensalidade.
   - Só desconta uma pequena taxa (ex: 5% a 8%) quando você vende.
2. Você cadastra o produto:
   - Nome: "Método Funil Anti-Vácuo para Estética"
   - Preço: R$ 67,00 (apenas Pix)
   - Em "Área de Entrega": você anexa o arquivo PDF "O_Funil_Automatico_de_Conversao.pdf".
3. A Kiwify te dá um Link de Checkout exclusivo.
4. No seu site, você só coloca esse link no botão!
   - O cliente clica, paga o Pix gerado na hora pela Kiwify.
   - O banco confirma em 2 segundos.
   - A Kiwify libera o download na tela e envia o PDF para o e-mail dele automaticamente!
   - Ninguém consegue baixar de graça.

------------------------------------------------------------------------------
OPÇÃO 2: MERCADO PAGO PIX AUTOMÁTICO (DIRETO NO SEU SITE VIA API)
------------------------------------------------------------------------------
Se você quiser que o QR Code e o Copia e Cola sejam gerados dentro do seu próprio site:
1. Você cria uma conta no Mercado Pago (mercadopago.com.br).
2. Em "Seu Negócio" -> "Configurações" -> "Gestão e Administração" -> "Credenciais".
3. Você pega o seu "Access Token".
4. O seu site usa essa chave para gerar um Pix exclusivo de R$ 67 para cada cliente.
5. O site fica monitorando o Mercado Pago a cada 3 segundos:
   - Status: "Aguardando pagamento..." (Download bloqueado 🔒).
   - Assim que o cliente transfere no banco, o Mercado Pago avisa o site: status "approved"!
   - A tela do site desbloqueia na mesma hora: "PAGAMENTO CONFIRMADO! BAIXE SEU PDF".

------------------------------------------------------------------------------
COMO O SEU SITE FOI CONFIGURADO AGORA:
------------------------------------------------------------------------------
O seu site agora possui um SISTEMA INTELIGENTE DE VERIFICAÇÃO com 2 modos:

MODO A (Checkout Externo Automático - Kiwify/Kirvano):
Basta colocar o link do seu produto cadastrado.

MODO B (Verificação Pix com Mercado Pago API ou Validação de Transação):
O site gera o Pix e inicia o relógio de checagem bancária ("Verificando pagamento no Banco Central...").
Os botões de download ficam BLOQUEADOS com cadeado até a confirmação!
